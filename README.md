# Exercícios 31 a 45 — Python

## Exercícios de Decisão

* **31.py** — Calcula e mostra o quadrado dos números entre 10 e 150.
* **32.py** — Recebe um número inteiro e calcula o seu fatorial.
* **33.py** — Calcula a série `1 + 1/2 + 1/3 + ... + 1/N`.
* **34.py** — Recebe um número e mostra os resultados da sua tabuada.
* **35.py** — Recebe 2 números inteiros, identifica o maior e calcula a soma dos números ímpares entre eles.
* **36.py** — Calcula a série `1 + 1/1! + 1/2! + ... + 1/N!`.
* **37.py** — Calcula a série de Fibonacci até o N-ésimo termo.
* **38.py** — Recebe 100 números positivos e mostra o maior e o menor valor.
* **39.py** — Calcula a quantidade de grãos em cada casa e o total de grãos de um tabuleiro de xadrez.
* **40.py** — Recebe 2 números inteiros e mostra todos os números primos existentes entre eles.
* **41.py** — Mostra todas as possibilidades de dois dados cuja soma seja 7.
* **42.py** — Calcula a série `1 + 2/3 + 3/5 + ... + 50/99`.
* **43.py** — Calcula quantos anos são necessários para Ana ficar mais alta que Maria.
* **44.py** — Recebe a base e o expoente e calcula o valor da potência.
* **45.py** — Calcula a série `1 - 2/4 + 3/9 - 4/16 + ... + 15/225`.
